# 小小张，今日星光为你而来

原创生日祝福网页：三维星空蛋糕、许愿、熄烛、烟花、星光寄语及原创配乐。

直接在浏览器打开 `index.html`。首页点击“开启生日惊喜”后播放音乐；完整祝福可在末尾的“重温生日祝福”中阅读。

个性化设置在 `birthday-config.js`，包括姓名、文案、落款、主题颜色、音乐与动画时间。

全部运行资源均随仓库提供，无需安装 Python 或 Node.js。Three.js 的 MIT 许可证位于 `assets/THREE-LICENSE.txt`。音乐与视觉由项目原创生成。

GitHub Pages 发布来源：`main` 分支、根目录 `/`。
